Privacy Policy

Effective 28 October 2026

Chess Bites is a YouTube channel with daily chess puzzles, run by Rave Nir. This policy covers the Chess Bites publishing tool (the "app"): a program the channel owner runs on their own computer to upload videos to the Chess Bites channel through the YouTube Data API. It also covers this website.

Who uses the app

The app is a private tool. Only the channel owner signs in to it, and only to publish to the Chess Bites channel. It is not offered to the public, and viewers never sign in to it or give it any data.

What Google data the app uses

When the channel owner signs in with Google, they allow the app to use these YouTube scopes:

  • youtube.upload to upload the daily videos to the channel.
  • youtube.force-ssl to set thumbnails, update the titles and descriptions of the channel's own videos (to link each puzzle to its solution), post a comment on the channel's own videos, and read the channel's name and ID and the publishing status of its own videos.

The app does not read, change or delete anything else. It does not access other channels, viewers' accounts, watch history, subscribers' personal data or private messages.

How the data is stored

The sign-in token that Google issues is stored only on the channel owner's computer, in a file that only the owner's user account can read. It is sent nowhere except to Google when the app calls the YouTube API. The app has no server and keeps no database of personal data. The only information it records locally is about its own videos, such as video IDs and upload status.

Sharing

No data obtained through Google APIs is sold, shared with third parties, used for advertising, or used to train AI or machine-learning models.

Chess Bites' use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

The app uses YouTube API Services. By using YouTube, viewers and the channel owner agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Watching, liking or commenting on Chess Bites videos happens on YouTube and is covered by those policies, not by the app.

Revoking access and deleting data

The channel owner can revoke the app's access at any time in the Google Account third-party connections page. Revoking access makes the stored token useless, and deleting the token file removes it from the computer. Videos already published stay on the channel until they are deleted in YouTube Studio.

This website

This site is a set of static pages hosted on GitHub Pages. It uses no cookies, no analytics and no forms. GitHub may keep standard server logs, as described in the GitHub Privacy Statement.

Children

Chess Bites videos are suitable for all ages but are not made specifically for children, and the app collects no data from anyone, including children.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
